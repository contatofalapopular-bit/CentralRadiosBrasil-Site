# Instalação — Site Público v22.16.1 Apoio Pix

1. Abra a pasta `01-SITE-PUBLICO`.
2. Envie **todo o conteúdo interno** para a raiz do repositório do Site Público (`CentralRadiosBrasil-Site`).
3. Substitua os arquivos existentes.
4. Não envie a pasta `01-SITE-PUBLICO` como uma subpasta.
5. Aguarde o GitHub Pages concluir e pressione `Ctrl + F5`.
6. Teste `https://centralradiosbrasil.com.br/apoie/`, o botão do cabeçalho e o botão de copiar a chave.

## Não alterar

Este pacote não exige alteração no Worker, D1, Admin ou Portal do Cliente.

## Rollback

A cópia original recebida está em `02-ROLLBACK`.
